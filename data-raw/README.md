# data-raw

- `qfracture-2012-c/`: ClinRisk's QFracture-2012 source (LGPL-3), unchanged,
  from https://github.com/nhsland/clinrisk-modules, commit
  `4e7cb71e565445715307fcf07eeb67830cb7bd11`, folder `qFracture/` (a mirror
  of http://svn.clinrisk.co.uk/qfracture, committed 28 December 2017). The C
  files were generated by ClinRisk on 5 March 2012 from a Stata dataset
  time-stamped 1 March 2012.
- `translate_c.py`: writes `R/equations.R` from the four C files:
  `python3 -I data-raw/translate_c.py data-raw/qfracture-2012-c/c R/equations.R`
- `c_reference.R`: compiles the C code with `R CMD SHLIB` and writes
  `tests/testthat/c_reference_fixtures.csv` (991 cases; 56 of them are
  rejected by the C input checks):
  `Rscript data-raw/c_reference.R . <empty build directory>`
